# remotedemo2

基于 WebRTC 的浏览器远程协作示例。被协助页面共享画面，控制端通过 WebRTC 数据通道发送鼠标、键盘和文本操作。

## 运行

在仓库根目录执行：

```powershell
pnpm --filter remotedemo2 dev
```

要求 Node.js `>=22.6`。`dev` 会先构建浏览器脚本，再启动服务。

## 使用

1. 打开 <http://127.0.0.1:32223/remote.js>，在需要被协助的浏览器页面中执行脚本。
2. 点击页面右下角的“开始远程协助”。
3. 脚本会生成并复制控制地址；协助者打开该地址即可查看画面并进行操作。

控制页面入口为 <http://127.0.0.1:32223/>。生产运行可使用 `pnpm --filter remotedemo2 start`。
